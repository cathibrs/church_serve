# Escala de Voluntários — Lagoinha Jundiaí

O sistema é um site: funciona no navegador do computador ou do celular, sem instalar nada.

## Para usar

1. Abra o endereço do site informado pela liderança.
2. Entre com o seu e-mail e a senha que o administrador lhe passou (dá para trocar depois, em **Alterar senha**).
3. Escolha a data, marque quem faltou e clique em **Gerar escala**.

Para trocar alguém, clique no nome. Tudo é salvo sozinho. Mais detalhes em `LEIA-ME.txt`.

## Para publicar o site

O passo a passo (Neon, carga inicial dos dados e Netlify) está em [`app/web/README.md`](app/web/README.md).

---

O `EscalaIgreja.exe` desta pasta é o programa anterior. Ele continua abrindo com os dados
antigos do computador, mas não conversa com o site: o que for feito nele não aparece na versão web.
